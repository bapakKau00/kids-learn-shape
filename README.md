# Shape Eby - Interactive Learning Game 🌈✨

Welcome to **Shape Eby**! This is a vibrant, interactive educational web application designed for young children to learn about shapes and sizes through engaging missions.

## 🚀 Game Missions

1.  **Misi 1: Radar Bentuk** 📡 - Students use a high-tech radar to find and sort specific shapes (Bulat, Segi Empat Sama, Segi Tiga, Segi Empat Tepat).
2.  **Misi 2: Makmal Saiz** 🧪 - Comparing sizes of common classroom objects like textbooks, chairs, and tables.
3.  **Misi 3: Master Detektif** 🕵️‍♂️ - A high-speed search mission where students find objects based on specific shape and size combinations.

## 📁 Project Structure

Organized for optimal performance and professional deployment:

- `assets/`
    - `audio/`: Catchy sound effects and professional voice-overs.
    - `images/`: Colorful backgrounds and game assets.
    - `videos/`: Immersive background animations.
- `css/`: Shared styling for uniform design.
- `[Root]`: All game logic and landing pages.

## 🔧 Technologies Used
- HTML5 / CSS3 (Vanilla)
- JavaScript (Vanilla)
- Responsive Design (Mobile & Desktop)
